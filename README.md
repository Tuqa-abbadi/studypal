# StudyPal Android App

Java + Android Studio project.

## Features
- User info screen
- Add, complete, and delete tasks
- Room local database
- Progress screen for last 24 hours
- Pomodoro timer (25/5)
- Timer finish notifications
- Daily summary notification at 9:00 PM

## Open the project
1. Open Android Studio.
2. Choose **Open**.
3. Select the `studypal_project` folder.
4. Let Gradle sync.
5. Run on emulator or device.

## Notes
- Android Studio may create `local.properties` automatically.
- On Android 13+, allow notification permission.
